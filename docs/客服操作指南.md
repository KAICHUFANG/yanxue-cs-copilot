# 客服操作指南（一页纸）

> 这是给客服同学看的。不需要懂技术，照着做就行。
> 系统只做一件事：**帮你想怎么回复家长**。家长不会用它，家长只会看到你发出去的话。

---

## 一、三条铁律（先记这三条）

1. **它写的是「你要发给家长的话」，不是给你看的建议。**
   想好再复制。它偶尔会写错，你要过一眼——尤其数字（时间、价格、名额）。

2. **右边面板「还缺 N 项」= 你要去问负责人。**
   系统没有的信息，它不会编，会留个空。那个空就是你的待办。

3. **有四样东西它给不了，只能你自己发：**
   公众号名片、进校预约填写示例截图、集合点导航照片、报名二维码（在推文里）。
   漏了家长就会在群里刷屏问。

---

## 二、第一次用：填 API Key（只填一次）

1. 双击桌面上的 **`启动工作台.bat`**
2. 会弹出一个黑色的窗口，别关它（关了系统就停了）
3. 几秒后浏览器自动打开。如果没打开，手动访问：<http://localhost:8501>
4. 页面最上面点开 **🔑 API 设置** → 把你自己申请的 Key 粘进去
5. 点 **保存并测试连接**
   - 看到绿色的「已保存到 .env，连接正常」= 成功，以后不用再填
   - 看到红色的「连不上」= 按它下面提示的三样依次查

> Key 从哪里来：打开 <platform.deepseek.com> 注册 → 左侧「API keys」→ 创建 →
> **只显示一次，当场复制**。充 10 块钱能用很久。

## 三、界面怎么看

```
┌──────────────────────────────────┬──────────────────┐
│ 🔑 API 设置（折叠，填一次就好）    │  当前活动         │
├──────────────────────────────────┤  还缺 N 项        │
│                                  │  ✓ 活动日期       │
│   对话（你打的字、它写的话）        │  ✗ 集合地点       │
│                                  │  ……              │
│  ┌────────────────────────┬────┐ │  [生成全部群文案] │
│  │ 在这里打字，回车发送     │发送│ │                  │
│  └────────────────────────┴────┘ │  ← 这块固定不动   │
│  [清空对话]  本次会话 N tokens    │                  │
└──────────────────────────────────┴──────────────────┘
```

- **左边**：所有的输入都在这里，没有别的输入框
- **右边**：当前这一期的信息和缺口。**对话再长它也不动**，随时能看
- 右边 ✗ 的那几项，就是还要问负责人补的

## 四、四种用法（照着说就行）

### 用法 1：家长问了，你想知道怎么回

直接在输入框打家长的问题（**原话照抄，不用改写**）：

```
家长问：这期几点集合？
家长问：两个人一起报名有优惠吗
家长问：需要带身份证吗
家长问：下雨怎么办
```

它会给你一段**能直接复制发出去**的话。

> 小技巧：不确定它说得对不对时，可以追问「依据是什么」或「推文里怎么写的」。

### 用法 2：补活动信息

```
集合地点在海南大学海洋生物标本馆
集合时间改成 15:00
名额改成 30 人
每组 4 到 5 个孩子
```

说完右边面板会立刻变化（✓ 多一个、缺项少一个）。

### 用法 3：要群通知文案（活动群里的）

按阶段说，一次要一段：

```
写个拉群欢迎语
写个进校预约提醒
写个活动前一天的活动提醒
写个当天的出发提醒
写个活动结束感谢
```

想一次要全部五段，就点右边的 **生成全部群文案** 按钮。

**这五段是固定的定稿模板**，系统会把当期数据填进去，不需要它「创作」。
拿到后**直接复制发群**，不要自己改措辞（改了就前后不一致）。

### 用法 4：要推广文案（拉到别的群 / 朋友圈）

```
写个私域群推广文案      → 发到别的家长群
写个朋友圈推广文案      → 发自己朋友圈（会自动写短，不超过 5 行）
```

这两种是**现写的**，每次不一样。可以追问「再活泼一点」「再短一点」。

## 五、发之前一定要看一眼的三件事

| 检查 | 为什么 |
|---|---|
| **数字对不对**（时间、价格、名额） | 它偶尔会把「18:00」写成「6 点」。数字错了比说错话严重 |
| **「结束感谢」里那句亮点** | 那句是系统按推文拟的草稿，要核对**现场是不是真这样**。拟不出来它会留个空让你填 |
| **有没有 `{{ }}` 这种括号** | 有就说明那项数据还没录，先补信息再生成，别带着括号发出去 |

## 六、出错了怎么办

| 现象 | 怎么办 |
|---|---|
| 页面打不开 / 白屏 | 看那个黑窗口还在不在。不在就重新双击 `启动工作台.bat` |
| 报 `AttributeError: 模块…没有属性` | **关掉黑窗口，重新双击启动**（程序更新了，进程还是旧的） |
| 报 `Port 8501 is already in use` | 上一次的窗口没关干净 → 任务管理器里结束 `python.exe`，再启动 |
| 一直转圈 / 提示「连不上」 | 打开 🔑 API 设置，点一次「保存并测试连接」，看它说哪里不对 |
| 它答得很离谱 | 先说「重新回答，注意不能说资料里没有的内容」；还不行就自己改 |

**通用一步**：遇到看不懂的错，先**重启一次**（关黑窗口 → 重新双击）。八成能好。

## 七、关于记录（你要知道这件事）

系统会把**每一次问答**记下来，写在：

```
data\logs\chat.jsonl
```

- **永久保留**，不会自动删
- 记的是：时间、你的名字、你问的、它答的
- **家长的手机号会打码**（138****5678），但问句里其它内容会原样保留

所以：**别在这个对话框里输入跟工作无关的东西。**

---

## 八、两条安全提醒

1. **`.env` 这个文件是你的钥匙，不要发给任何人**，也不要截图发群里。
2. **不要把它写的 Key、账号、密码发给家长**。家长只需要知道「扫码报名」「群里等通知」。

---

## 九、每天开工 / 收工

**开工**：双击 `启动工作台.bat` → 浏览器打开 → 开始用

**收工**：直接关掉那个黑色窗口（浏览器可以继续开着，但系统已停）

> 数据是自动保存的，不需要点「保存」。
> 关掉浏览器不会丢数据，但**关掉黑窗口系统就停了**。
