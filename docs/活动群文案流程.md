# 活动群文案流程（客服版）

> 给客服同学看的**总览**：什么时间、发什么、哪些要自己动手。
> 具体某一条想改，直接在对话框问助手；想自己翻，看本文档下半部分。

**品牌名统一用「山海科普」**（2026-10 老师已改，不再用「山海研学」）

> ⚠️ **本文档只写流程与人工项。文案原文在 [群文案原文.md](群文案原文.md)，那一页由 `tools/gen_copy_doc.py` 从数据生成，不要在这里手抄文案——抄一份就多一处会跟系统不一致。**

## 一、一页看懂

### 时间线是被一个约束决定的

> **进校预约只能在「活动前一天」和「活动当天」操作**，再早进系统选不到日期。

所以群不能建太早——建早了家长想约也约不了，只会反复问「什么时候能约」。**活动前两天建群刚好。**

### 五个阶段

| 阶段 | 什么时候发 | 发什么 | 系统能生成 | 要自己动手 |
|---|---|---|---|---|
| **① 拉群** | **活动前 2 天** | 欢迎语 + 时间表 | ✅ | — |
| **② 进校预约** | **活动前 1 天早上** | 预约文案 + **公众号名片** + **填写示例图** + 门禁提醒 + @所有人 | ✅ 文案 | ⚠️ **发公众号名片**<br>⚠️ **上传示例图**<br>⚠️ **改反馈时点** |
| **③ 活动提醒** | **活动前 1 天晚上** | 活动提醒 + **导航照片** | ✅ 文案 | ⚠️ 填集合时间地点<br>⚠️ **白天先收到导航照片** |
| **④ 出发提醒** | **活动当天早上** | 出发前提醒 | ✅ | — |
| **⑤ 收尾** | 结束后当晚 / 1–2 天后 | 感谢 → 回顾推文链接 | ✅ 文案 + ✅ 亮点初稿 | ⚠️ 核对亮点<br>⚠️ 先粘回顾推文 |

**⚠️ 加粗的三件事最容易漏**：公众号名片、填写示例图、导航照片——系统给不了，只能手动。

### ⑤ 收尾那两句不再是「自己想的空」

过去「今天孩子们______」和「里面记录了孩子们______」是留给客服自己写的空，实际总被拖到最后。
现在改成**系统先拟稿、客服只核对**：

| 要填的一句 | 系统从哪里拟 | 为什么要核对 |
|---|---|---|
| 感谢里的**现场亮点** | **当期活动推广推文**的原文 | 推文写的是「计划这么办」，现场未必完全照推文执行 |
| 回顾分享里的**具体细节** | **活动回顾推文**的原文 | 回顾推文是活动后写的，写的就是真实发生的 |
| 回顾分享里的**推文链接** | 从回顾推文原文里自动提取 | 没带链接时才需要人工补 |

拟出来的稿会在消息末尾单独标出来，并且**带上它依据的推文原句**，方便一眼核对：

```
🤖 下面这几处是系统按原文拟的稿，发之前核对一下现场是不是真这样：
· 现场亮点：「分组扮作五类小商人，掷骰走棋盘，走完生产、加工、买卖、合伙、交货全过程」
  依据当期活动推广推文：「分组扮作五类小商人，掷骰走棋盘，在三个小时里走完生产……」
```

**找不到依据就不写。** 推文里没有具体环节时，系统不会编，而是把占位符留着让客服写。

### 回顾推文要先「存」进去，系统才能用

活动结束后把**公众号回顾推文的全文**直接粘进对话框（不用说是哪一期）：

```
你：（粘贴整篇回顾推文）
助手：活动回顾推文已经存下来了：第16期（articles/reviews/review_第16期.md，2318 字）。
      活动字段一项都没动 —— 回顾推文讲的是已经办完的那一场，不是新一期。
你：写回顾分享
助手：（按这篇回顾拟好的转发文案 + 链接）
```

存下来的回顾推文**不会跟着换期消失**（活动记录每期都换，回顾是历史资料），
所以过两个月问「第十六期回顾里写了什么」也还能查回来。

#### ⚠️ 第 1 条里有一处必须改

`{{反馈时点}}` 默认是「今天下午6点」，**要根据建群时间调整**：

| 情况 | 改成什么 |
|---|---|
| 建群较晚（距活动不足 2 天，比如活动明天下午就开始） | **今天较晚时段** —— 当天必须拿到反馈 |

## 三、家长最常问的几件事（标准答法）

| 家长问 | 怎么答 | 别怎么说 |
|---|---|---|
| **孩子要预约吗** | 不用。预约主要是**车辆预约**，家长开车带孩子进校，车上的人都不用单独约。 | 别说「每个人都要预约」——家长会给自己和孩子各约一遍 |
| **从哪个门进** | 北门、东门、南门都可以，**西门走不了**。导航别走东南门，容易迷路。走北门最稳妥。 | 别说「所有门都能走」（西门出不去） |
| **要带身份证吗** | 不用。预约页面要填身份证号，但人到现场不用带实体身份证，开车进校就行。 | — |
| **预约成功有提示吗** | 一般会发短信，但**有时收不到**，稳妥是让家长自己进公众号的「访客预约进校」查状态。一直显示待审核就找我催。 | 别把「会发短信」说成必然 |
| **要家长陪同吗** | 默认不用陪同，孩子独立参加。如果需要陪同，我帮您跟策划组确认。 | 别武断说「必须陪」或「一定不用陪」——每期可能不同 |
| **几个孩子一组** | 我们会尽量把认识的孩子分在一组，具体到现场跟工作人员说一声，他们会尽量协调。 | **别报具体人数**（5 人还是 6 人说法不一，不承诺） |
| **能晚点到吗** | 活动会准时开始、不会等人，但您到了直接进来找工作人员就行。 | 别只说「不等人」（家长以为进不去了） |
| **下雨怎么办** | 见下方「下雨天安排说明」，整段发过去。 | — |

### 下雨天安排说明（整段复制）

```
📌 关于下雨天的活动安排说明

各位家长请知悉，如遇雨天，活动将按以下方式处理：

🌧 活动开始前下雨
如集合时间前遇雨导致活动无法正常开展，我们会提前在群里通知取消，费用全额退还。

🌧 活动过程中下雨
活动期间如遇阵雨，我们将转入室内备用场地继续开展，室外的环节会相应调整为室内活动，体验不打折～

请大家放心，我们已做好两手准备，随时关注天气变化，有情况第一时间群内通知！
```

## 四、人工必做清单（怕漏就看这个）

**活动前 2 天**

- [ ] 建群，发欢迎语（含时间表）

**活动前 1 天 · 白天**

- [ ] 确定集合地点、集合时间
- [ ] **向拍摄的同学收齐集合点导航照片**（当晚要发）
- [ ] 按建群时间确定 `{{反馈时点}}`，改好预约文案

**活动前 1 天 · 早上**

- [ ] 预约文案后**紧跟公众号名片**
- [ ] 补**填写示例截图**
- [ ] 发**进校门提醒**（北门/东门/南门，别走东南门）
- [ ] 发 @所有人 催办

**活动前 1 天 · 晚上**

- [ ] 活动提醒 + **导航照片**一起发

**活动当天早上**

- [ ] 发出发前提醒（含门禁提醒，导航照片不用再发）

**活动结束后**

- [ ] 当晚发感谢，**核对系统拟的亮点草稿**（现场是不是真照推文执行的）
- [ ] 回顾推文出来后，**把全文粘进对话框存下来**，再说「写回顾分享」
