# 活动群文案流程（客服版）

> 这一页是给客服同学看的**总览**：什么时间、发什么、哪些要自己动手。
> 具体某一条文案想改，直接在对话框问助手；想自己翻，看本文档下半部分。

**品牌名统一用「山海科普」**（2026-10 老师已改，不再用「山海研学」）

---

## 一、一页看懂

| 阶段 | 什么时候发 | 发什么 | 系统能给 | 要自己动手 |
|---|---|---|---|---|
| **① 建群当天** | 建群后立刻 | 欢迎语 | ✅ 文案 | — |
| **② 预约进校** | 建群后尽快（越早越好） | 预约提醒文案 + **公众号名片** + 填写示例图 + @所有人 | ✅ 文案 | ⚠️ **发公众号名片**<br>⚠️ **上传填写示例图**<br>⚠️ **改反馈时点** |
| **③ 活动前一天** | 前一天晚上 | 活动提醒 + **导航照片** | ✅ 文案 | ⚠️ 填集合时间地点<br>⚠️ **白天就要收到导航照片，当晚发出** |
| **④ 当天早上** | 家长出发前后 | 出发前提醒 | ✅ 文案 | — |
| **⑤ 活动结束后** | 当晚 / 1–2 天后 | 感谢 + 回顾推文链接 | ✅ 文案 | ⚠️ 写一句真实亮点<br>⚠️ 填回顾链接 |

**⚠️ 加粗的三件事最容易漏**：公众号名片、填写示例图、导航照片——这三样系统给不了，只能客服手动发。

## 二、每一条文案（可直接复制）

> `{{}}` 里的内容按当期活动替换。文案里的固定表述不要改，改了就前后不一致。

有问题随时在群里@我，我会尽快回复 🌿
```

### ② 预约进校 · 一共 4 条，按顺序发

**第 1 条 · 预约提醒文案**

```
📢【山海科普｜进校园活动预约提醒】
各位家长好，为方便大家进入海南大学校园，现将预约流程与注意事项整理如下：

✅ 预约步骤

1. 关注「海南大学」官方公众号

2. 点击底部菜单栏「私信」

3. 选择「访客预约进校」

4. 按以下信息填写：

- 被访人：{{被访人姓名}}
- 被访人电话：{{被访人电话}}
- 被访人单位：海南大学热带农林学院（农业农村学院、乡村振兴学院）

⚠️ 重要提醒

- 预约时间：请预约明天的进校权限

- 审核进度：{{反馈时点}}如未收到预约成功的信息提示，请及时告知我们，我们会协助催促审核

- 校内行车：进入校园后车速严禁超过30迈，超速被拍到会被列入2个月黑名单，无法再入校

- 活动结束后，大家可以体验一下海大的食堂，感受校园氛围~
```

**第 2 条 · 「海南大学」公众号名片** ← ⚠️ **必须手动发，系统没有这个链接**

文案第一句就是"关注「海南大学」官方公众号"。**如果不跟着发名片，家长根本不知道去哪儿找**，会直接在群里刷屏问。

**第 3 条 · 进校预约填写示例截图** ← ⚠️ **必须手动上传**

让家长看清「被访人姓名 / 电话 / 单位」三栏具体怎么填，避免填错导致审核不通过。

**第 4 条 · @所有人 催办**

```
@所有人 请各位家长朋友尽快预约进校，有问题请随时在群里@我，非常高兴为您服务[玫瑰]
```

#### ⚠️ 第 1 条里有一处必须改

`{{反馈时点}}` 默认写法是「今天下午6点」，**但要根据建群时间调整**：

| 情况 | 改成什么 |
|---|---|
| 建群较晚（距活动不足 2 天，比如活动明天下午就开始） | **今天较晚时段** —— 当天必须拿到反馈，否则来不及催审核 |
| 建群较早（距活动 2 天以上） | **明天下午** —— 次日再让家长反馈 |

**这是整个流程最容易出错的一环。** 按固定时间提醒，建群晚的活动就会来不及催审核，家长当天进不了校门。

### ③ 活动前一天 · 活动提醒

```
📢【山海科普｜活动提醒】

各位家长，明天就是「{{活动名}}」啦，请留意以下事项：

🕒 集合时间：{{集合时间}}
📍 集合地点：{{集合地点}}
🚗 出行方式：自驾，自行抵达现场集合
👕 着装：舒适的休闲裤、运动鞋，注意防晒
🎒 请自带：可循环水杯（现场提供饮用水）

⏰ 请准时到场，活动不补场、不等人

⚠️ 另外请再确认一次：进校预约是否已通过？
如未收到预约成功提示，请立刻在群里告诉我，我协助催促审核。

临时有事来不了，请提前告知我，方便我们调整物资 🌿
```

**紧跟着发导航照片** ← ⚠️ 手动发

**所以白天就要把照片收到。** 导航照片是当晚跟着活动提醒一起发的，不能等第二天早上——家长提前一天就知道怎么走、车停哪，当天早上才不会慌。

> 照片由团队拍摄的同学提供，客服需在**活动前一天白天之前**收齐。

☀️ 早上好～今天就是「{{活动名}}」啦！

出发前请再确认三件事：
1️⃣ 进校预约已通过（没约上的现在群里告诉我，我马上帮你催）
2️⃣ 水杯带了
3️⃣ 孩子吃过早餐、穿运动鞋

🕒 {{集合时间}} 在 {{集合地点}} 集合
📍 集合点导航照片昨晚已发到群里，找不到位置直接在群里@我

路上注意安全，我们现场见 🌿
```

> 导航照片前一晚已经发过了，这条不用再发图。

### ⑤ 活动结束后

**当晚 · 感谢**

```
🌿【山海科普｜「{{活动名}}」圆满结束】

感谢各位家长和孩子的参与！
今天孩子们{{写一句真实亮点，写明具体做了什么}}，收获满满～

📸 现场照片正在整理，之后会在公众号发布活动回顾，敬请关注
📅 下一期活动已在筹备，有消息第一时间在群里通知

有任何建议或想法，欢迎私信告诉我 🌹
```

> **亮点那句不要写空话。** 「孩子们玩得超开心」= 没信息。
> 写具体：「孩子们自己谈成了三笔交易，还盖了契约章」——这才是家长想看的。

**活动后 1–2 天 · 回顾推文**

```
📸「{{活动名}}」的活动回顾推文出来啦！

里面记录了孩子们{{具体细节：环节名或孩子的真实表现}}，还有现场照片～

👉 {{回顾推文链接}}

下一期报名开始后，我会第一时间在群里通知 🌿
```

## 三、人工必做清单（怕漏就看这个）

活动前：

- [ ] 确定集合地点、集合时间
- [ ] **活动前一天白天之前**向拍摄的同学收齐**集合点导航照片**（当晚随活动提醒一起发）
- [ ] 按建群时间确定 `{{反馈时点}}`，改好预约文案

发群时：

- [ ] 预约文案后**紧跟公众号名片**
- [ ] 补**填写示例截图**
- [ ] 发 @所有人 催办
- [ ] **活动前一天晚上**：活动提醒 + **导航照片**一起发

活动当天：

- [ ] 早上发出「出发前提醒」（导航照片前一晚已发，不用再发图）
- [ ] 现场有人没约上，立刻帮忙催审核

活动后：

- [ ] 当晚发感谢，亮点写具体
- [ ] 回顾推文出来后转发到群里
