# 活动群文案流程（客服版）

> 给客服同学看的**总览**：什么时间、发什么、哪些要自己动手。
> 具体某一条想改，直接在对话框问助手；想自己翻，看本文档下半部分。

**品牌名统一用「山海科普」**（2026-10 老师已改，不再用「山海研学」）

---

## 一、一页看懂

### 时间线是被一个约束决定的

> **进校预约只能在「活动前一天」和「活动当天」操作**，再早进系统选不到日期。

所以群不能建太早——建早了家长想约也约不了，只会反复问「什么时候能约」。**活动前两天建群刚好。**

### 五个阶段

| 阶段 | 什么时候发 | 发什么 | 系统能生成 | 要自己动手 |
|---|---|---|---|---|
| **① 拉群** | **活动前 2 天** | 欢迎语 + 时间表 | ✅ | — |
| **② 进校预约** | **活动前 1 天早上** | 预约文案 + **公众号名片** + **填写示例图** + 门禁提醒 + @所有人 | ✅ 文案 | ⚠️ **发公众号名片**<br>⚠️ **上传示例图**<br>⚠️ **改反馈时点** |
| **③ 活动提醒** | **活动前 1 天晚上** | 活动提醒 + **导航照片** | ✅ 文案 | ⚠️ 填集合时间地点<br>⚠️ **白天先收到导航照片** |
| **④ 出发提醒** | **活动当天早上** | 出发前提醒 | ✅ | — |
| **⑤ 收尾** | 结束后当晚 / 1–2 天后 | 感谢 → 回顾推文链接 | ✅ | ⚠️ 写一句真实亮点<br>⚠️ 填回顾链接 |

**⚠️ 加粗的三件事最容易漏**：公众号名片、填写示例图、导航照片——系统给不了，只能手动。

## 二、每一条文案（可直接复制）

> `{{}}` 里的内容按当期活动替换。固定表述不要改，改了就前后不一致。

### ① 活动前 2 天 · 拉群 + 欢迎语

```
📢【山海科普｜{{期次}}活动群】

各位家长好，欢迎加入{{期次}}「{{活动名}}」活动群 👋

本群用于发布本次活动通知、解答疑问，请留意群消息。

🗓 活动时间：{{活动日期}} {{活动时间}}
📍 活动地点：海南大学（海甸校区）
👦 参与对象：{{参与对象}}

📅 接下来的安排
· 明天早上：发布进校预约指引（预约只能在活动前一天和当天操作，所以明天才能约）
· 明天晚上：活动注意事项 + 集合点导航照片
· 活动当天早上：出发前提醒

有问题随时在群里@我 🌿
```

> **时间表是这段的关键。** 家长最常问「什么时候能预约」，提前说清就不用一个个回；
> 括号里那句「所以明天才能约」也很重要——让家长知道不是我们拖着不办。

---

### ② 活动前 1 天早上 · 进校预约（5 条，按顺序发）

**第 1 条 · 预约提醒文案**

```
📢【山海科普｜进校园活动预约提醒】
各位家长好，为方便大家进入海南大学校园，现将预约流程与注意事项整理如下：

✅ 预约步骤

1. 关注「海南大学」官方公众号

2. 点击底部菜单栏「私信」

3. 选择「访客预约进校」

4. 按以下信息填写：

- 被访人：{{被访人姓名}}
- 被访人电话：{{被访人电话}}
- 被访人单位：海南大学热带农林学院（农业农村学院、乡村振兴学院）

⚠️ 重要提醒

- 预约时间：请预约明天的进校权限

- 审核进度：{{反馈时点}}如未收到预约成功的信息提示，请及时告知我们，我们会协助催促审核

- 校内行车：进入校园后车速严禁超过30迈，超速被拍到会被列入2个月黑名单，无法再入校

- 活动结束后，大家可以体验一下海大的食堂，感受校园氛围~
```

**第 2 条 · 「海南大学」公众号名片** ← ⚠️ **必须手动发，系统没有这个链接**

文案第一句就是"关注「海南大学」官方公众号"。**不跟着发名片，家长找不到入口**，会直接在群里刷屏问。

**第 3 条 · 进校预约填写示例截图** ← ⚠️ **必须手动上传**

让家长看清「被访人姓名 / 电话 / 单位」三栏怎么填，避免填错导致审核不通过。

**第 4 条 · 进校门提醒** ← 系统能生成，直接复制

```
🚗 关于进校门的小提醒

社会车辆可以从【北门】【东门】【南门】进校，【西门】走不了（教职工应急出入口）。

⚠️ 导航上有时会把车导到「东南门」，那边容易迷路，而且不确定社会车辆能不能进，请不要走东南门。

➡️ 建议统一走【北门】，最稳妥。
```

> 为什么紧跟预约文案发：家长看到「预约明天的进校权限」后，紧接着就会想「从哪个门进」。
>
> **东南门这个提醒不能省。** 家长的导航自己会选路，你不主动说，他还是会走错。

**第 5 条 · @所有人 催办**

```
@所有人 请各位家长朋友尽快预约进校，有问题请随时在群里@我，非常高兴为您服务[玫瑰]
```

#### ⚠️ 第 1 条里有一处必须改

`{{反馈时点}}` 默认是「今天下午6点」，**要根据建群时间调整**：

| 情况 | 改成什么 |
|---|---|
| 建群较晚（距活动不足 2 天，比如活动明天下午就开始） | **今天较晚时段** —— 当天必须拿到反馈 |
| 建群较早（距活动 2 天以上） | **明天下午** —— 次日再让家长反馈即可 |

### ③ 活动前 1 天晚上 · 活动提醒 + 导航照片

```
📢【山海科普｜活动提醒】

各位家长，明天就是「{{活动名}}」啦，请留意以下事项：

🕒 集合时间：{{集合时间}}
📍 集合地点：{{集合地点}}
🚗 出行方式：自驾，自行抵达现场集合
👕 着装：舒适的休闲裤、运动鞋，注意防晒
🎒 请自带：可循环水杯（现场提供饮用水）

⏰ 活动会准时开始，不会因为个别家庭迟到而延后；如果路上耽误了，到了以后直接进来找工作人员就行。

⚠️ 最后再确认一次：进校预约是否已通过？
如未收到预约成功提示，请立刻在群里告诉我，我协助催促审核。

临时有事来不了，请提前告知我，方便我们调整物资 🌿
```

**紧跟着发导航照片** ← ⚠️ 手动发

**⚠️ 所以白天就要把照片收到。** 导航照片是当晚跟着活动提醒一起发的，不能等第二天早上。

> 照片由团队拍摄的同学提供，客服需在**活动前一天白天之前**收齐。

### ⑤ 活动结束后

**当晚 · 感谢**

```
🌿【山海科普｜「{{活动名}}」圆满结束】

感谢各位家长和孩子的参与！
今天孩子们{{写一句真实亮点，写明具体做了什么}}，收获满满～

📸 现场照片正在整理，之后会在公众号发布活动回顾，敬请关注
📅 下一期活动已在筹备，有消息第一时间在群里通知
```

> **亮点那句不要写空话。** 「孩子们玩得超开心」= 没信息。
> 写具体：「孩子们自己谈成了三笔交易，还盖了契约章」——这才是家长想看的。

## 三、家长最常问的几件事（标准答法）

| 家长问 | 怎么答 | 别怎么说 |
|---|---|---|
| **孩子要预约吗** | 不用。预约主要是**车辆预约**，家长开车带孩子进校，车上的人都不用单独约。 | 别说「每个人都要预约」——家长会给自己和孩子各约一遍 |
| **从哪个门进** | 北门、东门、南门都可以，**西门走不了**。导航别走东南门，容易迷路。走北门最稳妥。 | 别说「所有门都能走」（西门出不去） |
| **要带身份证吗** | 不用。预约页面要填身份证号，但人到现场不用带实体身份证，开车进校就行。 | — |
| **预约成功有提示吗** | 一般会发短信，但**有时收不到**，稳妥是让家长自己进公众号的「访客预约进校」查状态。一直显示待审核就找我催。 | 别把「会发短信」说成必然 |
| **要家长陪同吗** | 默认不用陪同，孩子独立参加。如果需要陪同，我帮您跟策划组确认。 | 别武断说「必须陪」或「一定不用陪」——每期可能不同 |
| **几个孩子一组** | 我们会尽量把认识的孩子分在一组，具体到现场跟工作人员说一声，他们会尽量协调。 | **别报具体人数**（5 人还是 6 人说法不一，不承诺） |
| **能晚点到吗** | 活动会准时开始、不会等人，但您到了直接进来找工作人员就行。 | 别只说「不等人」（家长以为进不去了） |
| **下雨怎么办** | 见下方「下雨天安排说明」，整段发过去。 | — |

### 下雨天安排说明（整段复制）

```
📌 关于下雨天的活动安排说明

各位家长请知悉，如遇雨天，活动将按以下方式处理：

🌧 活动开始前下雨
如集合时间前遇雨导致活动无法正常开展，我们会提前在群里通知取消，费用全额退还。

🌧 活动过程中下雨
活动期间如遇阵雨，我们将转入室内备用场地继续开展，室外的环节会相应调整为室内活动，体验不打折～

请大家放心，我们已做好两手准备，随时关注天气变化，有情况第一时间群内通知！
```
